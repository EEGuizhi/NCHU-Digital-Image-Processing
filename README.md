# NCHU-Digital-Image-Processing
NCHU Digital Image Processing 2024 (Course Name : Introduction to Image Processing)

- **Homework 1 programming part**:
  - Reduce image intensity levels
  - Zooming and shrinking
  - Image rotation, scaling, translation and interpolation
</br>

- **Homework 2 programming part**:
  - Histogram equalization
  - Edge enhancement (using Laplacian filter)
  - Unsharp masking
</br>

- **Homework 3 programming part**:
  - Fourier transform
  - Edge detection (using Sobel filter)
  - Highpass filtering
</br>

- **Homework 4 programming part**:
  - Noise reduction
  - Notch filtering
  - Image restoration (using Wiener filter)
</br>

- **Homework 5 programming part**:
  - Color image enhancement
  - Image segmentation
</br>

- **Term Project**:
  - Progressive color transfer for images of arbitrary dynamic range </br>
    (Please see the README.md file in `term_project` folder)
